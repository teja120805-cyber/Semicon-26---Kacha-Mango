# Experiments

Every experiment that touches `model/` or proposes a `pipeline/` change lives here as
`experiments/<experiment_name>/`, per `reports/V2_ARCHITECTURE_PLAN.md` section 10 and the mandatory
integration gate in section 8.

## Rules

- An experiment imports shared, unmodified code from `generator/`, `pipeline/`, `model/` where nothing
  changed — it never edits those packages in place to try something out.
- An experiment gets its own config and its own output directory (or references artifacts already
  written under `outputs/reports/` — see each experiment's `REPORT.md` for what's copied vs. referenced).
- **A change only merges into `pipeline/` or `model/` proper after it passes every criterion in the
  integration gate** (`evaluation/benchmark.py`), cited in the commit that merges it. Until then, it
  stays here, with an honest report — including if it failed.
- Production code (`pipeline/ranking.py::rank_classical` as the default ranking path) never changes
  automatically because an experiment ran. That is always a separate, deliberate code change.

### 90%-accuracy campaign (2026-08-16) — see [`ACCURACY_90_CAMPAIGN.md`](ACCURACY_90_CAMPAIGN.md) for the consolidated writeup

Nine further ideas, tried after A2 (`scale_range_v1`)/A6 (`multiway_tiebreak_v1`) integration,
against the then-current production baseline (74.36%@5px, n=156 — production is now 77.6%). All
nine rejected; the consolidated report explains the cross-cutting mechanism finding (raw ZNCC
score, not candidate discovery/ranking, is the real bottleneck on periodicity failures) that four
of them converged on independently.

| [`subpixel_grid_refinement/`](subpixel_grid_refinement/REPORT.md) | **Rejected** | Joint scale/rotation subpixel interpolation — real effect on 156/156 pairs (verified), but max shift 0.305px, far below the 5px tolerance; prior grid-density integrations already closed most of the gap this would recover. |

| [`pitch_aware_prominence/`](pitch_aware_prominence/REPORT.md) | **Rejected** | Surgical follow-up to `prominence_rerank` using a per-pair MEASURED periodic pitch instead of a generic radius — passed 6/7 integration-gate criteria on the production-seed benchmark (0.7436→0.7500), but **failed an independent second-seed validation** (0.6618→0.6324, 0 rescues / 4 breaks). The campaign's closest near-miss, and a cautionary example of single-seed overfitting. |
| [`oracle_ceiling_diagnostic/`](oracle_ceiling_diagnostic/REPORT.md) | **Diagnostic** (not a candidate) | Measured the best ZNCC achievable at ground truth under an ideal warp, per failing pair — **falsifies the campaign's headline "4x score gap" finding** (real gap is at most 1.048x; every failure is a near-tie under 0.05). Decomposed the then-current 40 failures into 45% candidate-generation / 22.5% tie-break / 32.5% scoring (superseded: the frozen benchmark now has 35 failures, split 37% discovery / 63% selection - `reachability_verification/`), and identifies a pool-internal gap statistic that flags 95% of failures while touching only 49% of pairs — making selective escalation to expensive methods affordable under the runtime criterion. |
| [`psf_gated_selection/`](psf_gated_selection/REPORT.md) | **Integration candidate** (5/7 gate; **best result to date**) | Builds the candidate pool with BOTH the production and PSF-matched (σ=1.6) templates and keeps whichever produces the more decisive match, judged by the pool-internal gap statistic — no threshold, no tuned constant, no ground truth. **0.7436 → 0.7756 (+3.21pp)** on the production seed and **0.6618 → 0.6985 (+3.68pp)** on an independent second seed. Across both (n=292): 14 rescued / 4 broken, **sign test p = 0.031** — the first statistically significant result in this project. Cuts broken pairs from always-blurring's 12 to 4, and reverts `barrel_charging`/`speckle_saltpepper`/`vignette_gamma` to exact baseline. Criteria 1, 2, 3 pass for the first time; 4 and 5 fail on 1–2 pair margins. Runtime 2.0x. |
| [`psf_second_seed/`](psf_second_seed/REPORT.md) | **Replicates — but not for integration yet** | Independent second-seed validation (seed 618234) of `psf_matched_template`'s sigma=1.6. **The gain replicates and is larger on the new seed: +0.0368 (0.6618 → 0.6985) vs +0.0256 on production; +0.0308 pooled over 292 pairs.** First result in this project to survive an independent-seed check. However, combining both seeds shows the per-family harm is **systematic, not noise** — all four net-negative families are degraded-acquisition ones and none is net-positive on either seed — and the overall +9 net is not significant (sign test p=0.16). Recommends a binary gate using the spectral estimator's ranking rather than integration as-is. |
| [`psf_matched_adaptive/`](psf_matched_adaptive/REPORT.md) | **Rejected** | Per-pair blur estimated blind from the image power spectra, to replace `psf_matched_template`'s single global sigma. Unscaled: protects every degraded family but forfeits the gains (pooled **unchanged**, 0.7436). Dev-scaled (k=1.555): 0.7628, still below the fixed sigma's 0.7692, and collapses `ho_vignette_gamma` 0.800 → **0.400**. Falsifies the estimator's core assumption — the template/Search spectral difference is not a pure Gaussian blur; noise biases sigma down, gamma biases it up. **Also records a benchmark-mining warning: four frozen-benchmark runs now exist in this line, so the leading config needs second-seed validation before any integration decision.** |
| [`psf_matched_template/`](psf_matched_template/REPORT.md) | **Not integrated** (fails gate 4 & 5) — **best result to date** | Blurs the template to match the Search image's passband, correcting a ~16x sharpness mismatch between the two acquisition paths (Reference carries 0.06px of blur into template space; Search carries 1.0px). Pooled **0.7436 → 0.7692 (+2.56pp)** at **1.00x runtime**, and the **first experiment ever to improve `validation`** (0.900 → 0.950) rather than tie its ceiling. Fails on per-family regressions concentrated entirely in degraded-acquisition families (worst_case −0.25, vignette_gamma −0.20). Also documents a protocol defect: `development` contains no degraded family, so dev-only sweeps are blind to over-blur. |
| [`crop_uniqueness_ceiling/`](crop_uniqueness_ceiling/REPORT.md) | **Diagnostic + candidate** | Shows accuracy is governed by crop `uniqueness_score` (0.500 at 0 vs 0.898 above it; the campaign-time figures were 0.438 / 0.880) and that **periodicity is a confound, not a cause** (0.4pp effect once uniqueness is held fixed). Refutes the ill-posedness hypothesis: 154/156 crops have a unique origin, and no failure picked a >0.95-identical location. Locates the real bottleneck as **template fidelity** — the two Search locations differ at 0.732 content ZNCC while the template separates them by 0.0098. Deliverable: a pool-internal confidence gate answers 51% of pairs at **97.5%** accuracy / 69% at **92.5%**. |
| [`pitch_aware_prominence_v2/`](pitch_aware_prominence_v2/REPORT.md) | **Rejected** | Diagnosed and fixed the exact bonus-driven flip that broke the v1 formula on all 10 pairs it ever changed (both seeds) — clipping the re-score to a penalty-only term (`score + gamma*min(prominence,0)`) fully fixes all 4 second-seed breaks, but is a complete no-op everywhere else (0/156 pairs changed at any tested strength, up to 4x v1's peak gamma). Conclusively shows v1's apparent gain was never real periodicity signal. |

### 2026-08-17 batch — see [`BATCH_2026-08-17_REPORT.md`](BATCH_2026-08-17_REPORT.md) for the consolidated writeup

Screened against the current production baseline (77.6%@5px, n=156) and, for the diagnostics, against
the 22 reachable failures identified by `reachability_verification/`. **Production is unchanged.** The
batch report consolidates every entry below except `hypothesis_ensemble/`, which stands on its own.

| Experiment | Status | One-line result |
|---|---|---|
| [`axis_decomposition/`](axis_decomposition/REPORT.md) | **Diagnostic** — hypothesis supported | Decomposes each failure's error vector onto the lattice axes: the residual failures are **one-dimensional** — the error is 100% along a lattice axis at the median with a cross-axis residual of only 1.47px, so the pipeline is confused about *which lattice period* it sits on and nothing else. Recorded in the batch report as its most valuable result; changes what is worth trying next, not the pipeline. |
| [`lowfreq_1d/`](lowfreq_1d/REPORT.md) | **Near-miss** — does not clear the bar | Exploits what ZNCC discards by construction (absolute brightness and contrast, removed by zero-mean/variance normalisation). Mean-brightness agreement prefers truth on **15/22 (68%)** reachable failures, against a pre-registered bar of >70% (binomial p = 0.067). The strongest single signal of roughly nineteen screened this session — but the bar was fixed before running and is not being moved. |
| [`hypothesis_ensemble/`](hypothesis_ensemble/REPORT.md) | **Diagnostic** — hypothesis refuted | Tests whether arg-max over ~160 hypotheses suffers winner's curse: robust aggregates (mean/median/trimmed) should favour truth. They do not — at best 5/22 (23%). The inversion is the finding: on periodic structure, robustness across hypotheses is a **decoy signature, not a truth signature**, which closes the whole consensus/voting/robust-aggregation family with a mechanism. The inverted signal is reported and explicitly **not** recommended. |
| [`alternative_scores/`](alternative_scores/REPORT.md) | **Rejected** (both measures) | OTSDF/MACE correlation filters and phase-based (log-Gabor) matching, screened on the same 22 failures. OTSDF sits at chance (≤11/22) with the α=0 null control behaving correctly and full MACE collapsing to no discrimination at all; phase matching is *worse* than chance at 4/22 (18%). Both discard the low-frequency boundary content that discriminates — the same mechanism that sank P1. |
| [`gated_escalation/`](gated_escalation/REPORT.md) | **INTERIM — not integrated, not validated** | Runs production unchanged and escalates to a denser hypothesis grid **only** on pairs already flagged `ambiguous` (35.3% after the 0.990 recalibration, so ~2.06x predicted runtime). Three tuning surfaces gave +6.7pp with 7 rescues / 0 breaks (p = 0.008), but the frozen run traded 8 rescues for 5 breaks, worsened the catastrophic rate (14.1% → 16.7%) and dropped `held_out` (0.700 → 0.675). The settled recommendation in the batch report's Addendum 2 is **DO NOT INTEGRATE**; the deciding validation sweep was incomplete at the time of writing. |
